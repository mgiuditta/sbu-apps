# FreeBadge
Le quattro promesse di sbu.dev come pill (`radius-pill`, `surface-raised`, punto `success`) e il footer "Parte di sbu.dev" con `sbu-mark`.

**Il consumatore fornisce** nulla: il contenuto è fisso ed è identico in tutte le app.

- Le pill vanno nel secondo screenshot App Store e nella schermata di onboarding; il footer in fondo a Impostazioni di ogni app, con link a sbu.dev.
- Il testo delle pill non si riformula: sono quattro delle sei promesse del blocco fisso della descrizione App Store; "Dati solo su questo iPhone" è la promessa "dati solo sul dispositivo".
- Non fare: aggiungere una pill "Lascia una recensione", cambiare il punto verde in un'icona a stella.
