## 2. Cosa sta dietro il paywall

Gratis ("edizione limitata", a volte rimossa secondo le recensioni):
- Ascolto di poche suonerie del catalogo, interrotto da pubblicità ogni 10-30 secondi.
- Tutorial video per esportare con GarageBand.

A pagamento (VIP o acquisti singoli):
- Creare una suoneria da un proprio file audio (taglio, dissolvenza in entrata e in uscita).
- Convertire un video in audio (19,99 € da solo).
- Catalogo completo di brani scelti dal canale TikTok dello sviluppatore.
- Niente pubblicità, cronologia delle modifiche.

In pratica tutto il valore (tagliare 30 secondi di un audio) è a pagamento. Il leader US (iUUAPP) dà tutto gratis con pubblicità.

## 3. UX

### Flusso del leader, schermata per schermata

1. **Onboarding**: 2-3 pagine di promessa ("suonerie illimitate"), poi richiesta di registrazione (Apple/Google) e paywall con prova; nessuna X visibile (decine di recensioni).
2. **Schermata principale**: catalogo per categorie (hit, classici, suoni divertenti) con anteprima; pulsante "+" per creare la propria. Niente ricerca (lamentela ricorrente IT e US).
3. **Azione chiave**: scegli audio (File, Rullino video, catalogo) → editor con forma d'onda e due maniglie, dissolvenza in/out, anteprima → "Esporta" → l'app apre GarageBand con un progetto → video tutorial: in GarageBand tieni premuto il progetto → Condividi → Suoneria → nome → Usa come suoneria standard / assegna a un contatto. Da iOS 26 basta il file audio ≤30 s e "Usa come suoneria" dal menu Condividi.
4. **Impostazioni**: abbonamento, ripristina acquisti, supporto, privacy, cronologia.

### Cosa amano gli utenti (4-5★)
- "Finalmente posso fare le suonerie che voglio e gratis", "non utilizzo più la suoneria predefinita".
- Facile e veloce quando funziona; la coppia app + GarageBand evita di pagare 1-2 € a brano su iTunes.
- Assegnare una canzone a un contatto per riconoscere chi chiama.

## 4. Fattibilità iOS senza server

| Funzione | Framework Apple | Note |
|---|---|---|
| Import audio da File e da altre app | `fileImporter` / `UIDocumentPickerViewController`, `UTType.audio`, Document Types + "Apri in" (share-in senza estensione) | mp3, m4a, wav, aiff, caf |
| Audio da video del Rullino | `PhotosPicker` (nessun permesso libreria), `AVURLAsset`, `AVAssetExportSession` preset `AppleM4A` | sostituisce l'IAP da 19,99 € |
| Registrazione dal microfono | `AVAudioRecorder` / `AVAudioEngine` | `NSMicrophoneUsageDescription` |
| Musica dalla libreria | `MPMediaPickerController` | solo brani senza DRM (`assetURL` nil per Apple Music): va detto chiaramente |
| Forma d'onda | `AVAssetReader` + downsampling in un tipo puro testabile, disegno con `Canvas` / Swift Charts | |
| Taglio a 0,1 s, max 30 s (40 s per GarageBand) | `CMTimeRange` su `AVAssetExportSession.timeRange` | |
| Dissolvenza 1-5 s, volume | `AVMutableAudioMix` con `setVolumeRamp` | |
| Unione di più clip | `AVMutableComposition` | |
| Anteprima con loop della selezione | `AVPlayer` + `AVPlayerLooper` o boundary observer | |
| Export .m4r / .m4a | AAC in contenitore MPEG-4; `.m4r` è solo l'estensione | |
| "Usa come suoneria" (iOS 26+) | `ShareLink` / `fileExporter` verso File: azione di sistema nel menu Condividi per file ≤30 s non DRM | nessuna API pubblica; affidabile da File, a volte assente da altre app: salvare in File e guidare |
| Percorso iOS 17-25 | salvare in File, poi GarageBand (gratis, Apple) → importa da File → Condividi → Suoneria; oppure Finder su Mac con il .m4r | guida a passi fissi, leggibile, non un video veloce |
| Cronologia | SwiftData, file in Application Support | |
| Tono di ricarica | App Intent "Riproduci suono" usabile in un'automazione di Comandi | facoltativo |

Entitlement ed estensioni: nessuno obbligatorio. Microfono (Info.plist), Document Types per ricevere file, `PrivacyInfo.xcprivacy` (UserDefaults, file timestamp). Nessuna share extension necessaria per la 1.0 ("Apri in" basta).

Parti NON copiabili e alternativa on-device:
- **Catalogo di brani (canale TikTok, hit, classici)**: contenuti con licenza e server. Alternativa: solo audio dell'utente; al massimo una piccola raccolta di toni generati sul dispositivo (sintesi con `AVAudioEngine`) o registrati da noi, mai brani di terzi.
- **Impostare la suoneria in un tocco / per contatto**: nessuna API pubblica (il campo suoneria di `CNContact` non è esposto, la cartella suonerie è privata). Alternativa: esportazione + passi guidati; il contatto lo sceglie l'utente in Contatti.
- **Progetto GarageBand pronto (.band)**: formato non documentato, non lo generiamo. Alternativa: file audio salvato in File, che GarageBand importa.
- **Download da TikTok/YouTube/Spotify**: vietato (5.2.3) e richiede rete. Alternativa: video già nel Rullino (registrazione schermo inclusa).

## 5. Rischi App Review

- **4.3 nicchia**: categoria satura (decine di "Ringtones for iPhone" quasi identici, molti cloni di template). Una Sbu con editor serio, zero catalogo, zero paywall e un nome descrittivo si distingue, ma il revisore vede "ringtone maker" n-esimo: nelle note serve dire cosa fa di diverso (taglio esatto + guida per iOS 17-26, tutto sul dispositivo).
- **4.3 tra le Sbu**: sovrapposizione bassa. Noise genera suoni (rumore), Tuner analizza il microfono, Transcribe trascrive audio: nessuna taglia ed esporta clip. Evitare di condividere schermate-tipo con Transcribe (import audio + forma d'onda) senza differenziare la Cosa sola.
- **4.2 funzionalità minima**: rischio basso se c'è editor vero (forma d'onda, dissolvenze, unione, video, registrazione, cronologia); alto se è un "taglia e condividi" di una schermata.
- **5.2.x proprietà intellettuale**: niente brani nel bundle o negli screenshot; screenshot con audio nostri. 5.2.3: nessun download da servizi terzi. 5.2.5 marchi Apple: non usare "iPhone", "GarageBand", "iTunes" nel nome o nell'icona; nella guida citare GarageBand come prodotto di Apple, senza loghi.
- **2.5.1 API pubbliche**: non toccare percorsi privati delle suonerie. **2.3.1 accuratezza**: non promettere "imposta in un tocco"; descrivere i passi reali.
- **5.1.1 privacy**: solo microfono, chiesto al primo "Registra"; PhotosPicker senza permesso libreria. Nessun dato salute. Età 4+ (niente contenuti utente condivisi).
- **Una cosa sola**: *taglia i 30 secondi giusti di un suono e li fa diventare la tua suoneria*. La figura sulla schermata è la durata della selezione (es. "0:28" chiuso dal punto fermo), in `ink`.

## 6. Stima

- Giorni-agente per una 1.0 pari al leader (senza catalogo): **4-5** (import multi-sorgente 1, forma d'onda + editor + anteprima 1,5, export/dissolvenze/unione 1, guida iOS 17-25/26 e cronologia 0,5-1, test, stringhe, screenshot 1). Più un test su dispositivo reale per entrambe le strade di impostazione (iOS 18 con GarageBand e iOS 26).
- Complessità: **M** (AVFoundation semplice, ma il passo finale dipende dal sistema e va verificato su dispositivo).
- Abbonamento stupido da pagare: **5/5**: 7-10 €/settimana per tagliare un audio, cosa che da iOS 26 il sistema imposta da solo.
- Fattibilità: **4/5**: tutto on-device con AVFoundation; manca solo l'impostazione in un tocco, che nessuno ha via API pubblica.
